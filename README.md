# Assignment 5 – Intro to Data Visualization

This repository contains the code for Assignment 5 of the Intro to Data Visualization course.

## Overview

This is a static web project, primarily written in HTML (with some JavaScript), designed for data visualization assignments.

## How to Run

1. **Clone or download this repository**  
   Click the green "Code" button on GitHub and choose "Download ZIP" or clone the repo with:
   ```sh
   git clone https://github.com/MatthewLabasan/data-vis-a5.git
   ```

2. **Open the main HTML file**  
   Locate the main HTML file (usually `index.html`) in the project folder.

3. **View in your browser**  
   Double-click the HTML file, or right-click and choose “Open with” > your preferred web browser.

   That's it! No installation or server needed.

## Project Structure

- `index.html` – Main web page.
- `.js` files – JavaScript for dynamic behavior or visualizations.
- Any data or asset files are in the same directory or nearby folders.

## Requirements

- Any modern web browser (Chrome, Firefox, Edge, Safari)
